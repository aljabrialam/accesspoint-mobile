# Security policy

Please report security issues privately through GitHub: **Security → Report a vulnerability** on this repository, or on the main repository [aljabrialam/accesspoint](https://github.com/aljabrialam/accesspoint/security). Don't open a public issue for security problems.

The app runs in scenario mode and makes no network calls to model services. Dependency notes, data handling and the full policy: [main repository SECURITY.md](https://github.com/aljabrialam/accesspoint/blob/main/SECURITY.md).
